# 🚀 AI Resume Builder

A web-based resume-building application designed to help users create professional resumes quickly and easily.

🌐 **Live Demo:** https://airesumebuilderwebsite.netlify.app/

## ✨ Overview

AI Resume Builder is a web application developed to simplify the process of creating professional resumes. It provides an easy-to-use interface that helps users prepare and organize their professional information into a resume.

The project is built using the MERN stack, combining a modern frontend with a backend and database to provide a complete web application.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **Deployment:** Netlify

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/vedikakulkarni-23/AI_Resume_Builder.git
```

### 2. Navigate to the Project Folder

```bash
cd AI_Resume_Builder
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
```

### 4. Install Backend Dependencies

Open another terminal:

```bash
cd server
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the server directory and add the environment variables required by your backend configuration.

### 6. Run the Application

Start the frontend and backend using the development scripts configured in their respective `package.json` files.
